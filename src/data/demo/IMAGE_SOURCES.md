# Джерела демо-зображень

Усі зображення в `src/data/demo/images/` тимчасові, лише для демоверсії.
Перед запуском магазину їх замінюють фото з вашого каталогу.

| Файли | Джерело | Ліцензія |
|---|---|---|
| `hero`, `snk-pace`, `snk-night`, `snk-eqt`, `snk-mid`, `snk-chuck`, `snk-neon` | Фото з Unsplash у демо-даних [vendure-ecommerce/vendure](https://github.com/vendure-ecommerce/vendure) (автори: Xavier Teo, Imani Clovis, Nikolai Chernichenko, Thomas Serer, Mitch Lensink, Chuttersnap) | Unsplash License |
| `watch-*`, `bag-*`, `puffer-*`, `softshell-*`, `track-*`, `hoodie-black-*`, `hoodie-olive-*`, `hoodie-women-*`, `zip-hoodie-*` | Демо-дані Magento Luma, [magento/magento2-sample-data](https://github.com/magento/magento2-sample-data) | AFL-3.0 / OSL-3.0 |
| `snk-campus-*`, `snk-zoom`, `snk-floral-*`, `levis-*`, `nike-tee`, `belt`, `sunglasses`, `cap` | Демо-дані [nopSolutions/nopCommerce](https://github.com/nopSolutions/nopCommerce) | nopCommerce Public License 4.0 (AGPL v3 з додатковими умовами) |
| `tee-*`, `hoodie-*`, `henley-*`, `jeans-grey-*`, `jacket-*`, `blazer-*`, `sport-set-*`, `snk-minimal-*` | Демо-дані [bagisto/bagisto](https://github.com/bagisto/bagisto) (згенеровані зображення) | MIT |
| `pf-*`, `wallet-*` | Студійні рендери, створені скриптом `scripts/render-studio.mjs` | власні |

Фото товарів відомих брендів (Adidas, Nike, Converse, Levi's, Ray-Ban) взято з демо-даних
названих проєктів і використано лише як приклад вигляду картки. Ціни, описи та наявність
у демо-каталозі умовні.

Умови цих ліцензій розраховані на демо-дані відповідних проєктів. Для робочого магазину
демо-фото не використовуються: їх замінюють вашими фотографіями.
